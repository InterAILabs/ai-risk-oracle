# v0.1.2-beta — Portable receipts and MCP Registry readiness

InterAI Risk Oracle `v0.1.2-beta` tightens the integration surface for the
agent-before-execution policy gate.

Highlights:

- portable trust-receipt signature verification across runtimes;
- TypeScript and Python SDK helpers for receipt lookup/signature checks;
- Certifi-backed TLS portability in the Python package;
- official MCP TypeScript client conformance coverage;
- validated MCP Registry remote `server.json`;
- guided activation measurement separated from paid/external adoption;
- bounded synthetic availability/latency history;
- public 30-day design-partner pilot brief.

This remains a controlled technical beta. It does not guarantee factual truth
or replace domain-specific/human controls for critical or irreversible actions.
